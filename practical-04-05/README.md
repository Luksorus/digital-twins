## Запуск

Unity 6000.4.6f1, Built-in Render Pipeline. Добавить папку UnityProject через Unity Hub, открыть Assets/Scenes/Practical04_05.unity и нажать Play.

F1 — общий вид; F2 — пешеход; F3 — станция; F4 — карта. WASD — перемещение, стрелки влево/вправо — поворот. H — скрыть памятку. Для ввода сначала щёлкнуть внутри Game.

Меню Practicals → Build city and evidence пересоздаёт сцену, изображения камер и десять проверок. Сохранить собственные изменения под другим именем перед повторной генерацией.

Жёлтая капсула на контрольном снимке — временный объект физического опыта; в сохранённую сцену она не включена. Исходный Walker с CharacterController остаётся в проекте.
