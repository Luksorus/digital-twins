# Практическая 10–11

Вращающиеся двери шкафов и входная дверь, доступ к предметам только при открытом шкафе, вентилятор с физическим сдуванием предметов и подъёмные жалюзи.

Unity **6000.4.6f1**. Открыть `UnityProject/Assets/Scenes/Practical10_11.unity`, нажать Play, щёлкнуть Game и пройти в комнату через портал. WASD — ходьба, стрелки — поворот, Page Up/Down — наклон камеры. O — дверь под прицелом, E — взять предмет или нажать выключатель, R — отпустить, F — вентилятор, B — жалюзи. F2 — персонаж, F5 — обзор комнаты. Для доступа к обратному порталу открыть входную дверь.
