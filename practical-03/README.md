## Запуск

Открыть папку UnityProject через Unity Hub в Unity 6000.4.6f1. Открыть Assets/Scenes/Practical03.unity. Во вкладке Game выбрать Display 1, 2 или 3.

Меню Practicals → Build scenes and evidence пересоздаёт только сцену этой практической, изображения камер и verification.txt. Скриншоты интерфейса сохраняются отдельно и не переснимаются автоматически. Перед повторной генерацией сохранить собственные изменения сцены под другим именем.

DOCX сохранён из первоначального комплекта; упоминания UnityPracticals и Results в нём относятся к прежней общей структуре. В новой структуре проект находится в UnityProject, изображения — в images, журнал — в verification.txt. Markdown адаптирован к новой структуре.

## Клавиши

Стрелки — движение X/Z, E/Q — движение вверх/вниз. R/F — масштаб X, T/G — масштаб Y, V/B — масштаб Z. X/Y/Z — вращение, Shift меняет его направление. Tab — автоматический режим, Backspace — сброс Transform. В Play Mode сначала щёлкнуть внутри Game.
