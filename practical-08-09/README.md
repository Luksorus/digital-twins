# Практическая 8–9

Порталы между городом и комнатой, физическая мебель, перенос предметов и выключатель света.

Открыть `UnityProject` в Unity **6000.4.6f1**, сцену `Assets/Scenes/Practical08_09.unity`, нажать Play и щёлкнуть Game. Перед персонажем находится портал в комнату. WASD — движение, стрелки — поворот, Page Up/Down — наклон камеры, E — действие по прицелу, R — отпустить предмет. F2 — персонаж, F5 — комната, F1/F3/F4 — город/станция/карта. Для перемещения мебели идти вплотную в неё.

`Assets/Scenes/Practical06_07.unity` сохранена как исходный город для генератора комнаты. В Build Settings включена только итоговая сцена 8–9. Practicals → Build room and evidence пересоздаёт комнату и кадры 01–09. `-batchmode -executeMethod RoomRuntimeVerification.Begin` запускает проверки Play Mode и сохраняет кадры 10–12. Сделать копию своей сцены перед повторной генерацией.

Все PNG являются изображениями настоящих камер Unity. Проверки Play Mode вызывают игровые методы и физическое перемещение контроллера; нажатия клавиатуры автоматически не воспроизводятся.
